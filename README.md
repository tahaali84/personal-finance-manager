# Personal Finance Manager 💰

A modern web application to manage personal finances efficiently.  
Track income, expenses, savings, and monitor spending habits with an easy-to-use interface.

## 🚀 Features

- Add and manage income & expenses
- Track financial transactions
- Categorize spending
- View balance and summaries
- Responsive and user-friendly UI
- Fast performance using React + Vite

## 🛠️ Tech Stack

- Vite
- JavaScript
- CSS / Tailwind CSS
- Local Storage / Backend (if added)
